# JARVIS Vision Assistant - Data

This folder will contain or document the test images used to evaluate
the JARVIS Vision Assistant.

## Planned Data

Approximately 30–50 images containing common everyday objects.

Examples:
- laptops
- phones
- bottles
- chairs
- backpacks
- people
- vehicles

Images may include photographs collected by the student and
appropriate public/sample images.

## Labels

The project uses a pretrained YOLO object-detection model. Object
labels are provided by the pretrained model rather than a custom
training dataset.

## Purpose

These images will be used to test the detection ability and
processing speed of the completed application.
